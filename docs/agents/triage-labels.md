# Triage Labels

Vocabulary for tickets and issues:

- `status:needs-triage`: Newly proposed ticket or feature, awaiting spec alignment.
- `status:needs-info`: Blocked on user input or missing technical constraints.
- `status:ready-for-agent`: Fully specified vertical slice ready for implementation.
- `status:in-progress`: Currently being actively developed.
- `status:ready-for-review`: Code written, tests passing, ready for review.
- `status:done`: Completed, verified, and merged.
- `priority:p0-critical`: Core security, auth, video playback, and shorts elimination.
- `priority:p1-high`: Search, subscriptions, library, UI polish.
- `priority:p2-medium`: Offline caching, gesture enhancements.
